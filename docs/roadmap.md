# Roadmap

Possible directions from here—not promises, just ideas:

- Mobile app (e.g. React Native)
- Richer analytics dashboard
- Multi-token support
- Subscription templates
- API for third-party integrations
- Governance token
- Cross-chain support

Status and priorities are up to the maintainers. For where things stand right now, see the main [README](../README.md#status).
