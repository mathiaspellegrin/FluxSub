FluxSub frontend. For setup and architecture, see the [repository root README](../README.md) and [/docs](../docs).

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app). So—the usual Next setup.

## Getting started

Run the dev server first:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. You’ll see the app. Edit `app/page.tsx` and the page updates as you go. Pretty standard.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to optimize and load [Geist](https://vercel.com/font)—Vercel’s font. Nothing to configure there.
